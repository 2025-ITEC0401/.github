- **Programming Language** : `Python 3.10`
- **Deep Learning Framework** : `PyTorch 2.3.1`, `TensorFlow 2.17.0`
- **GPU Computing** : `CUDA 12.1`, `cuDNN`, `cuML`, `cuDF`, `cuPY`
